# NEXORA Gaming Top-up
Static HTML/CSS/JS site. No backend or database needed.

## Publish with GitHub Pages
1. Extract ZIP.
2. Upload all files and the `assets` folder to your repository root.
3. Settings → Pages → Deploy from branch → `main` → `/ (root)`.

## Pages
- Home `index.html`
- Free Fire `freefire.html`
- eFootball `efootball.html`
- Checkout `checkout.html`
- Policy `about.html`
- Support `contact.html`

Order details are sent to WhatsApp via prefilled message; this static site does not verify payments. Do not request passwords or OTPs. Game logo image URLs are remote and need internet; if a logo fails to load, fallback title text appears.
